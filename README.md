# HemoAyuda

Aplicación web de seguimiento de episodios de sangrado y medicación para personas con hemofilia.

-- No sustituye las indicaciones del equipo de hematología ni constituye asesoramiento médico.

## Créditos

Modelo 3D «Músculos humanos» de Grab3D (https://grab3d.com/es/models/anatomy/human-muscles/), licencia CC0 1.0. Contiene contenido generado con ayuda de IA (según su LICENSE.txt). Se usa una versión optimizada en `models/cuerpo.glb`.
